A fully responsive landing page for a fictional AI startup **NexaAI**, built from scratch with **pure HTML, CSS, and JavaScript** (no frameworks). Created as part of the **SuPrazo Jr. Web Developer Assessment**.

> Demonstrates responsive design, modern UI/UX, animations, and clean code structure.

## ✨ Features

- 🧭 Sticky responsive navbar with mobile hamburger menu
- 🎯 Hero section with gradient headline & animated background
- ℹ️ About section (two-column, responsive)
- 🚀 Features / Services grids
- 💬 Testimonials section
- 🌗 Light / Dark theme toggle
- 📱 Fully mobile-responsive

## 🛠 Tech Stack

`HTML5` · `CSS3` · `JavaScript (ES6)` · `Font Awesome` · `Google Fonts (Inter)`

## 💻 How to Run

```bash
# No build step needed — just open the file
open index.html
# or use a live server
python -m http.server 8000
```

Then visit `http://localhost:8000`.
